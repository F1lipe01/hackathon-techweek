## 2. Direction from the Slack discussion

Full thread: [`sources/slack/team-channel.md`](../sources/slack/team-channel.md)

**Ana Aguiar: an LLM as the interface to the home.** Her takeaway from MobiCom was that LLMs or agents will become the interface between humans and digital services, so an LLM interface to a connected home could be a good option. She asked what it would look like.

**Proposal: show it through one situation that combines several whiteboard ideas**, such as looking after the house while someone is away.

- "I'm away until Sunday. Keep the plants watered and reduce the heating while I'm gone." The agent checks the sensor readings, works out what needs doing, and adjusts the plan if the person comes home earlier.
- "Where did I leave my keys?" The agent checks recent observations and reports where they were last seen.
- It should recognise when something is not possible and explain why: "I can water the plants, but I can't reduce the heating because the thermostat isn't connected."
- At that stage there was no need to work out how detection works. Assume the sensors provide the last known location and focus on how the LLM uses it.

**Proposal: use the interface to cut the effort of setting rules** for all devices. Rules set by voice command or generated by AI, then adapted in real time to the situation.

## 4. First-pass fit with what we were given

This section is analysis added while filing, not a team decision. The Slack discussion happened before we had the kit, the MCP guide or the mentors' steer.

The kit is: an LTE IoT gateway, a camera, a temperature and humidity sensor, a smoke alarm, a smart plug, a smart bulb, and a door contact sensor. Details in [04-kit-and-access.md](04-kit-and-access.md); what each device exposes through the MCP is in [10-mcp-in-practice.md](10-mcp-in-practice.md).

| Idea | What the kit offers | Gap or risk |
|---|---|---|
| LLM interface to the home | The MCP server is exactly this: 18 tools an agent can call | Altice already demo this in their own guide, so on its own it will not surprise them |
| Rules by voice or generated by AI | Scenario tools: create, activate, run | "Adapted in real time" is logic we would build on top |
| Away-from-home caretaker | Security arming (`AWAY`), the bulb, the plug, the climate sensor, the smoke alarm, the camera, and the door sensor to notice an early return | No thermostat and nothing that waters plants. A heater or a small pump on the smart plug could stand in, but there is only one plug |
| Explaining what it cannot do | Device lists and capabilities tell the agent what exists | Fits our kit literally: "I can't reduce the heating because no thermostat is connected" is true here |
| Lost & found ("where are my keys?") | The camera feed plus a vision model | Nothing in the MCP gives object locations. The observation memory would be ours to build, and one fixed camera sees one area |
| Security systems | Three security tools, alarm history, smoke alarm, camera, the door sensor | Closest to what the platform already does |
| Elder assist, kid monitoring, pets | Camera, smoke alarm, climate sensor, the door sensor | Privacy questions will come up in Q&A |
| HVAC automation | Climate sensor to read, smart plug to switch one appliance | No thermostat. The sensor reports only every 5 to 30 minutes, so nothing reacts live |
| Fridge inventory, recycling | Camera only | No dedicated hardware |

Three things bear on the choice:

- The mentors want to be surprised by a **useful use case** and said **not to underestimate the camera** ([02-challenge.md](02-challenge.md)).
- The organisers expect teams to say plainly **what is real and what is simulated** ([01-event.md](01-event.md)).
- **Altice already pitches several of these.** Their public product page lists security, energy management, AI-powered automation, a "Virtual Concierge Assistant" and aging in place ([02-challenge.md](02-challenge.md)). Of the whiteboard list, security systems, HVAC automation and elder assist sit inside what they sell. Lost & found, plants, fridge inventory, recycling, pets and kid monitoring do not appear there.
