## Checked for planted instructions

The organisers may seed material with instructions aimed at teams that hand everything to an AI. Each file was checked on 16 Nov 2026 when it was filed:

- **PDF:** no JavaScript, no embedded files, no hidden text layer (plain and layout extractions match), three links, all to VS Code and ChatGPT documentation. The pages were also rendered and looked at.
- **Templates (.docx, .pptx):** no hidden, white or tiny text. The slides contain no text at all, only layout images.
- **Transcript and Slack text:** nothing addressed to an AI. The English lines about "real-life tarzan" in the transcript are a video playing near the microphone.

Anything added later should get the same check before it is used.
