## Brainstorm (before 2 Nov, dates unknown)

**Sofia Martins** [16h10]

**Ana Aguiar** [10h40]
Do we have any progress here? At MobiCom, it seems obvious that LLMs or agents will become the interface between humans and digital services. So, an LLM interface to a connected home could be a good option. What would it look like?

**Filipe** [11h17]
Yes, I agree that an LLM interface to a connected home is the way to go here... Maybe we could demonstrate it through one situation that brings together a couple of the ideas we discussed, like looking after the house while someone is away.

For example, someone could say, “I’m away until Sunday. Keep the plants watered and reduce the heating while I’m gone.” The agent could check the sensor readings, work out what needs doing, and adjust the plan if the person comes home earlier. Another example could be, “Where did I leave my keys?” The agent could check recent observations and report where they were last seen.

It should also recognise when something isn’t possible and explain why: “I can water the plants, but I can’t reduce the heating because the thermostat isn’t connected.”

[11h20] I’m not sure we need to work out exactly how the LLM would work, for example how the keys are detected at this stage; we could assume the sensors provide information about their last known location and focus on how the LLM uses it to answer. Nowadays an LLM is smart enough to just do the technical part on its own

**Mushahid Hussain** [11h24]
We can also use this interface to reduce the effort and time required to set the rules for all devices. We can set the rules through voice command or use AI to generate rules. These rules can then be adapted real-time based on the situation.
